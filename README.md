# Minecraft Photomosaic Parallel Pipeline

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Ensure the `minecraft_textures` and `sample_images_24` folders are in the same directory as `main.py`.

## Running the pipeline
Run the main script:
`python main.py`

## Large Datasets
The full 2,000-image dataset (`sample_images_2000.zip`) is too large for GitHub. You can download it here: [https://github.com/yavuzceliker/sample-images].
